# מסלול השקה — מהמצב הנוכחי לגבייה

מסמך אחד, לפי הסדר. מחליף את הרשימה הכללית ב־[LAUNCH-CHECKLIST.md](LAUNCH-CHECKLIST.md) (שם נשארים פרטי התוכן).
**אין לעבור לשלב הבא לפני שהקודם הושלם.** השלבים המסומנים 🔒 משנים משהו בחשבון האמיתי ודורשים אישור מפורש שלך ברגע הביצוע.

| מצב נוכחי | |
|---|---|
| קוד, בדיקות מקומיות, אזור ניהול | הושלם. כל הבדיקות עוברות |
| בדיקת תשלום מול Sandbox של Morning | **לא בוצעה** |
| Cloudflare Access ואזור הניהול | **לא הוגדר** (חסום) |
| מיגרציה 0003 על המסד האמיתי | **לא הוחלה** |
| סליקה חיה | **כבויה** (`mock`, `ALLOW_LIVE_PAYMENTS=no`) |

## המסלול שנבחר: בדיקה חיה אחת ב־₪1 (במקום Sandbox)

הוחלט לדלג על Sandbox. במקומו יש מוצר בדיקה זמני, "בדיקת סליקה (₪1)", שלא מופיע ברשימה הציבורית.
הוא נרכש רק בכתובת `https://nursery.o-yaku.com/?test=1`, ורק כל עוד השרת מאפשר זאת (`LIVE_TEST_PRODUCT=yes`).

```bash
./scripts/go-live-test.sh                       # בדיקות, גיבוי, ואחרי שמקלידים LIVE: הדלקת סליקה חיה + מוצר ה־₪1
./scripts/go-live-test.sh --remove-test-product # אחרי הבדיקה: סליקה חיה נשארת, מוצר הבדיקה יורד
./scripts/go-live-test.sh --revert              # חזרה למצב בטוח: בלי סליקה חיה
```

**לפני שמריצים, חשוב לדעת:**
- **זה כסף אמיתי.** בזמן שהסליקה החיה דולקת, כל מי שיש לו את הקישור יכול לשלם. לא לשתף את הקישור לפני סיום הבדיקה, ולהריץ `--remove-test-product` או `--revert` מיד אחריה.
- **האתר החי משתנה.** הסקריפט מפרסם את הקוד שבתיקייה על גבי מה שעכשיו באתר. אם באתר החי יש שינויים שאינם ב־GitHub (למשל הבאנר "הסליקה ממתינה להפעלה"), הם יוחלפו. הסקריפט שומר עותק של הדפים החיים בתיקייה `live-snapshot-…` לפני כל שינוי, ומציג אילו קבצים ישתנו. אם יש שם שינויים שחשוב לשמר, יש להעביר את התיקייה לבדיקה לפני שממשיכים.
- **נוצר מסמך אמיתי ב־Morning.** עסקה של ₪1 מפיקה חשבונית מס/קבלה אמיתית. אחרי ההחזר צריך לבטל או לזכות אותה ב־Morning לפי הנהלים של העסק.
- **העסקה נספרת באזור הניהול כמכירה אמיתית** עד שמטפלים בה. ביטול שובר באתר חוסם מימוש בלבד ואינו מוריד אותה מהסיכומים.
- **הבדיקה הזאת היא גם הבדיקה הראשונה מול Morning האמיתית.** אם משהו לא מתאים בבקשה, התשלום ייכשל לפני שנגבה כסף. אם הוא עבר, יש לוודא במסמך ב־Morning שהסכום הוא ₪1 בדיוק, בלי מע״מ כפול.
- **חברות סליקה מגדירות לפעמים סכום מינימום לעסקה.** אם ₪1 נדחה, אפשר לבדוק עם חברת הסליקה, ולחלופין לקנות את החולצה (₪120) ולהחזיר.
- **סוד המפתח לא נשלח לשום מקום.** הוא מוקלד ישירות ל־wrangler. מפתח של חשבון ה־Sandbox לא מתאים כאן; נדרש המפתח של החשבון האמיתי.

**מה בודקים בעסקה:**
1. נכנסים ל־`/?test=1`, מוסיפים לסל את "בדיקת סליקה (₪1)", משלמים בכרטיס אמיתי.
2. חוזרים לאתר ורואים הזמנה ששולמה ושובר (מסומן כשובר אמיתי, בלי "לדוגמה").
3. ב־Morning: מסמך חדש, סכום ₪1, פרטי הלקוח נכונים.
4. החזר דרך Morning או חברת הסליקה. מתעדים מה קרה.
5. מריצים `--remove-test-product` או `--revert`.

## שלב 4 — העלאה במצב בדיקה 🔒

עדיין `PAYMENT_MODE=mock`. הסדר חשוב.

```bash
npx wrangler d1 export oyaku-founders-orders --remote --output backup-before-0003.sql
npx wrangler d1 migrations apply oyaku-founders-orders --remote      # מחיל 0003 בלבד
npx wrangler deploy
npx wrangler d1 execute oyaku-founders-orders --remote --file scripts/backfill-admin.sql
```

- [ ] האתר הציבורי, הסל והשובר עובדים כרגיל
- [ ] `/admin` בלי התחברות מפנה ל־Access. עם המייל שלך נפתח
- [ ] `/api/admin/me` בלי עוגייה לא מחזיר נתונים
- [ ] `/api/morning/notify` אינו חסום ב־Access
- [ ] יצוא CSV נפתח באקסל עם עברית תקינה

## שלב 5 — סליקה חיה 🔒

רק אחרי שלבים 1–4.

```bash
npx wrangler secret put MORNING_API_KEY_ID          # מפתחות Production; לא בצ'אט
npx wrangler secret put MORNING_API_KEY_SECRET
npx wrangler secret put NOTIFY_SIGNING_SECRET       # אם עדיין לא הוגדר בפריסה
```

ב־`wrangler.jsonc`: `PAYMENT_MODE=morning_live`, `ALLOW_LIVE_PAYMENTS=yes`, `MORNING_API_BASE=https://api.greeninvoice.co.il/api/v1`, `MORNING_AUTH_BASE=https://api.morning.co`, `PUBLIC_BASE_URL=https://nursery.o-yaku.com`. אחר כך `npx wrangler deploy`.

- [ ] **עסקה אמיתית אחת בסכום נמוך, שאתה מבצע בעצמך** (למשל חולצה אחת)
- [ ] ההזמנה עברה ל־`paid` ושובר מוצג, **בלי** סימון „לדוגמה”
- [ ] המסמך ב־Morning תקין, והסכום זהה
- [ ] באזור הניהול ההזמנה נספרת ב„מכירות אמיתיות”
- [ ] החזר של העסקה הזו מתבצע מול Morning (ביטול שובר באתר חוסם מימוש בלבד ואינו מחזיר כסף)
