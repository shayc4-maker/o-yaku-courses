# לפני גבייה — מה חסר

## תוכן שחייב להשלים
- [ ] **מועד פתיחה** (`ROUND_OPENS_AT`) — ממנו נגזר הסיום, 14 יום אחרי.
- [ ] **מועדי מימוש** לכל מוצר: מתי סדנאות, מתי מוכנים כלים, ממתי מתחילה „שנה” של מ״ר.
- [ ] **סדנת קרמיקה קבוצתית**: משך, מיקום, מה כלול (חומר, שריפה, זיגוג), מה קורה אם לא נאספו ארבעה משתתפים.
- [ ] **סדנת קרמיקה פרטית**: משך, מספר משתתפים, מה כלול.
- [ ] **כלי בהזמנה אישית**: תהליך העיצוב, זמן אספקה, חומר וגימור.
- [ ] **חולצות**: מידות וגזרות ואיך בוחרים מידה (בסל, בטופס, או בתיאום אחרי הרכישה).
- [ ] **אקדמה**: נפח או משקל שק, דרגה, איסוף או משלוח.
- [ ] **מ״ר במשתלה**: תנאי השכרת שטח — מה מותר להביא, אחריות על העצים, גישה וביקורים, חידוש אחרי שנה.
- [ ] **איסוף / משלוח**: לכל מוצר.
- [ ] **פרטי עסק בתחתית**: שם העסק, סוג (מורשה/פטור) ומספר, כתובת למשלוח מסמכים, טלפון/מייל.
- [ ] **תנאי רכישה ומדיניות ביטולים**: כולל ביטול עסקה לפי חוק הגנת הצרכן, החזרים, ומה קורה אם ההקמה מתעכבת.
- [ ] **מדיניות פרטיות קצרה**: האתר שומר שם, טלפון ואימייל לצורך ההזמנה.
- [ ] **הצהרת נגישות**, אם חלה על העסק.
- [ ] תמונה: לוודא זכויות או להחליף בתמונה מההדמיה.
- [ ] לאשר את הנוסח „אחרי התשלום אצור איתכם קשר כדי לתאם את המימוש” (`index.html`) ואת הנוסחים בדף מצב ההזמנה.
